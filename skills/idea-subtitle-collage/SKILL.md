# 想法转字幕拼图

把用户原始想法转换成“人物主画面＋连续字幕条”，并接到现有抖音图文队列。

## 制作

1. 读取原始想法和用户指定人物。已有明确身份、口吻和配图选择时直接执行。
2. 保留观点与情绪，把素材整理成 2—7 句有递进关系的短句；第一句引出主题，后续交代事实、反差和收尾。图上的每一句都属于文案，不把正文只放在发布栏里。
3. 对时效性的价格、用量与公告回查当前来源。区分 API 单价、订阅权益和实际使用量；来源不足时保留转述或疑问口吻。另写完整正文、20 字内标题、5 个话题候选。
4. 准备人物底图：已有照片可直接使用；用户允许生图时，先查看头像，再用可用生图工具生成无文字的人物场景，保留人物辨识度。遵循对应生图工具 Skill。让人物居中、下部留出深色衣服或背景；所有中文交给排版脚本。
5. 按 [references/input-format.md](references/input-format.md) 写 JSON，运行渲染脚本。默认标识 `创作者评论 · AI配图`；真实照片改成 `创作者评论 · 照片配图`。用户自己的观点不写成配图人物的原话。
6. 打开成品检查人物裁切、每句顺序、字号和零间距，再展示最终图片。长句报错时拆句或删减，不降低到手机无法阅读的字号。
7. 需要接入素材队列时使用 `--post-dir`。一张字幕拼图就是一张发布图片，不把其中的字幕条数当作发布图片数，也不为了凑 8 张而重复图片。

## 排版

- 默认 3:4、1080×1440。
- 主画面占比为 `min(0.82, max(0.48, 1 - 字幕条数 × 0.075))`；例如第一句＋4 条为 70%，第一句＋5 条为 62.5%。
- 第一句在主画面靠下位置；后续从底图下部裁取窄带，白字黑描边、水平居中、条间距 0。
- 保持原生字幕截图效果，不额外增加海报标题、价格徽章、卡片框或购买按钮。

## 运行

```bash
python3 -m pip install -r requirements.txt
python3 scripts/render_image_collage.py \
  --image /absolute/path/person.png \
  --script /absolute/path/post.json \
  --post-dir /absolute/path/content/001_内容名称
```

输出是一张拼图和正文/标题/话题文件。使用已安装的 `$douyin-image-post-scheduler`，调用其 `scripts/prepare_queue.py` 并传入 `--image-count 1` 做素材预检。若没有发布 Skill，展示本地素材包即可。此 Skill 完成创作和导出；用户明确要求发布时，再交给发布 Skill 处理已登录账号与平台核验。
